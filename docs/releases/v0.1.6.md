# Pokachy v0.1.6

Pokachy v0.1.6 refreshes the public website for the first-user pilot while keeping the native Omarchy plugin experience unchanged.

## Highlights

- Reworked the landing page around a quieter, minimal Pokachy identity: “Poke. That’s it.”
- Added the polished pixel-parrot artwork to the public website, privacy, support, and account-deletion pages.
- Simplified the signed-out experience and removed duplicate decorative parrots.
- Added Pokachy's X profile to the footer and kept account deletion available through the privacy and support pages instead of the signed-out home page.
- Preserved the existing Omarchy panel icon and plugin assets.
- Aligned CLI, Worker API/config, package metadata, lockfile, and plugin manifest to `0.1.6`.

## Verification

- The full repository verification suite and GitHub CI must pass on the release commit.
- Production deployment is performed separately from the release tag and must verify the exact deployed revision plus public endpoints.
- The release workflow rebuilds Linux amd64/arm64 archives and publishes them with `SHA256SUMS`.
