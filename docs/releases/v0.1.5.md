# Pokachy v0.1.5

This patch release includes the native Omarchy panel polish merged in PR #3.

- Refined square panel layout, spacing, alignment, and compact last-poke times.
- Clearer poke, reply, waiting, and sending states with a native hand action.
- Improved hover feedback, keyboard focus, and focus recovery when actions become unavailable.
- Open conversation history by activating a contact avatar; hovering or clicking the surrounding row stays passive.
- Keep keyboard selection visible above profile photos without tooltip text obscuring it.

Linux amd64 and arm64 archives include the CLI, installer, user service, brand assets, and all six Omarchy QML components. The installer verification now explicitly requires the three new panel components.

## Publication

Preparation does not publish a tag or deploy the Worker. Merge the release preparation branch through CI, then tag the resulting merged-main commit `v0.1.5` when publication is authorized. The existing tag workflow reruns the full suite, rebuilds both archives, and publishes the GitHub release. Its archives will have their own published checksums; local candidate checksums are not substitutes for those rebuilt assets.

ARM64 is cross-build/content-verified, not executed on ARM hardware. No fresh live inbox, GitHub consent, or real desktop notification test was performed for this panel-only patch. A Worker deployment, if desired for version alignment, uses the separate guarded deployment workflow; a release tag does not deploy it.
