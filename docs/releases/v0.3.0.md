# Pokachy v0.3.0

Pokachy v0.3.0 adds `pokachy tui`, a live full-screen terminal view of your inbox, friends, and friend requests.

## Changes

- Add `pokachy tui`: poke, poke back, accept or decline requests, add friends, dismiss pokes, browse history, block, and toggle quiet mode from one screen. Press `?` for all keys.
- Update the view live over the same event connection the daemon uses, with reconnect backoff and a 30-second refresh fallback; the header shows `live` or `offline`.
- Lay out names by terminal column so Chinese, Japanese, Korean, emoji, and accented names stay aligned, and keep the screen intact on narrow terminals.
- Exit with a sign-in hint when the device session has been revoked.
- Add homepage Open Graph and X card metadata with a 1200×630 social preview image.
- Align CLI, Worker, package, and Omarchy versions to `0.3.0`.

## Verification and rollout

The release runs the complete repository verification suite before publishing Linux archives, checksums, and the matching standalone Omarchy plugin. No database migrations or production configuration changes are included. Production deployment remains a separate workflow; deploy it to publish the homepage preview metadata.

The terminal view was driven in a pseudo-terminal against a disposable local Worker, including live delivery and reconnection, and rendered through two terminal emulators. It has not been exercised against production or in a desktop terminal application.
