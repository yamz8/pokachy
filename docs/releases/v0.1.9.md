# Pokachy v0.1.9

Pokachy v0.1.9 helps the Omarchy panel find a freshly installed CLI without restarting the desktop session.

## Changes

- Fall back to `~/.local/bin` for panel status, watch, history, actions, and setup while preserving custom PATH precedence.
- Keep action arguments separate from shell commands.
- Refresh the pilot checklist with live email sign-in, device approval, friendship, and real desktop notification evidence.
- Align CLI, Worker, package, and Omarchy versions to `0.1.9`.

## Verification and rollout

The release runs the complete repository verification suite before publishing Linux archives, checksums, and the matching standalone Omarchy plugin. Production deployment separately verifies the exact deployed revision. No database migrations or production configuration changes are included.

The two-account pilot was tested on one physical Omarchy desktop with v0.1.8 before this patch. The PATH fallback was separately checked in a disposable native process fixture. Fresh GitHub consent, a second physical desktop, and ARM hardware execution remain outside that evidence.
