# Pokachy v0.1.7

Pokachy v0.1.7 makes installing and connecting a Linux computer substantially simpler and gives the Omarchy panel its own minimal repository.

## Highlights

- Reduced the normal setup path to the installer followed by `pokachy init`.
- Added a dedicated `/install` page with copyable commands, manual verification, lifecycle guidance, and troubleshooting.
- Added architecture detection, stable release assets, SHA-256 verification, safe archive extraction, and temporary-file cleanup to the public installer.
- Made `pokachy init` resumable and able to configure notifications and the native Omarchy plugin through Omarchy's plugin manager.
- Added `pokachy doctor`, verified `pokachy update`, and narrowly scoped `pokachy uninstall` commands.
- Published the native panel separately at `yamz8/pokachy-omarchy`, without the Worker or CLI source tree.
- Made release publication coordinate the CLI archives, bootstrap installer, checksums, and matching Omarchy plugin snapshot.
- Aligned CLI, Worker API/config, package metadata, lockfile, and plugin manifests to `0.1.7`.

## Verification

- The full repository verification suite and GitHub CI must pass on the release commit.
- The standalone plugin export must pass `omarchy plugin validate`.
- Production deployment remains separate from the release tag and must verify the exact deployed revision plus public endpoints.
