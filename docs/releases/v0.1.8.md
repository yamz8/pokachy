# Pokachy v0.1.8

Pokachy v0.1.8 makes the Omarchy panel easy to install or repair directly from the Pokachy CLI.

## Highlights

- Added `pokachy omarchy install` as the explicit, idempotent panel command.
- Kept Omarchy's native validation, security confirmation, and bar-placement flow for new installations.
- Enabled an existing disabled panel automatically and left an already enabled panel unchanged.
- Reused the same panel logic from `pokachy init` instead of introducing overlapping `setup` or `configure` commands.
- Updated CLI help, diagnostics, installation documentation, and the public install page around the new command.
- Aligned CLI, Worker API/config, package metadata, lockfile, and plugin manifests to `0.1.8`.

## Verification

- The full repository verification suite and GitHub CI must pass on the release commit.
- The standalone plugin export must pass `omarchy plugin validate`.
- The install page must render the new command and its copy control without browser errors.
- This release has no database migrations.
- Production deployment remains separate from the release tag and must verify the exact deployed revision plus public endpoints.
