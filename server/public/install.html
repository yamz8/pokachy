Linux native · friends only

Get poking
in two commands.

Install Pokachy, connect this computer in your browser, then send a tiny signal to a friend.

Linux on amd64 and arm64. No sudo required.

Quick start

Install, then connect.

terminal
  1. 01
    $ curl -fsSL https://pokachy.com/install.sh | sh
  2. 02
    $ pokachy init

01

Install

The installer chooses the right Linux release, verifies its checksum, and installs the Pokachy command locally.

02

Connect

pokachy init opens a secure browser sign-in. Compare the displayed code before approving this desktop.

03

Poke

Add a friend, then send the smallest possible hello. No feed, chat, or noise.

What the installer does

Small and local.

  • Downloads the current amd64 or arm64 release.
  • Checks its SHA-256 checksum before installing.
  • Installs to your local user directory without sudo.
  • Leaves connection and notification setup to pokachy init.

Omarchy

Put Pokachy in your bar.

During setup, Pokachy can offer Omarchy’s native plugin flow. You can also add it yourself:

omarchy plugin add https://github.com/yamz8/pokachy-omarchy.git --enable
